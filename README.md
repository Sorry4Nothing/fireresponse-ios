# FireResponse iOS

Native iOS-App (Swift, SwiftUI) für FireResponse, die App für Jugend- und Kinderfeuerwehren im Kanton Zürich: Übungen aus Lodur, Ja/Nein-Anmeldung, Kontakt und Push.

Das Backend liegt in [Sorry4Nothing/fireresponse-api](https://github.com/Sorry4Nothing/fireresponse-api). Die API-Beschreibung steht dort unter `docs/api/`. Die Android-Schwester-App ist [Sorry4Nothing/fireresponse-android](https://github.com/Sorry4Nothing/fireresponse-android).
