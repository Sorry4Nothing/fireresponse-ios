# Endpunkte und Zugriff

Erzeugt aus der Rechte-Matrix (`apps/api/test/rechte-matrix.test.ts`) und `docs/api/openapi.yaml`; nicht von Hand ändern. Neu erzeugen: siehe [postman.md](postman.md).
